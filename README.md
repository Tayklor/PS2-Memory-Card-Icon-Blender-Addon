## Install:
Edit > Preferences > Get Extensions > Install from Disk.

Select the ZIP and enable PS2 Icons.

## Import:
File > Import > PS2 Icon (.icn)

Includes UVs, textures, colors, smoothing and normals.

Merge by Distance (0.0001 m) is enabled by default.

## Export:
File > Export > PS2 Icon (.icn)

Apply All Transforms is enabled by default.
